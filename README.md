# 0xvaibhav

Personal portfolio for [0xvaibhav.com](https://0xvaibhav.com), built around my backend, infrastructure, and product engineering work.

Built with Next.js, TypeScript, Motion, and Paper Shaders. Company marks are provided by [Logo.dev](https://www.logo.dev/).

## Development

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

To display company logos, add a Logo.dev publishable key:

```bash
NEXT_PUBLIC_LOGO_DEV_TOKEN=pk_...
```

Run `npm run check` before shipping.
